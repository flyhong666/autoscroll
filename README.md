# 自动刷视频

一款基于 Android **无障碍服务**的全场景自动滚动工具，支持刷短视频、新闻资讯、小说阅读、社交动态、直播挂机等所有可滑动应用。集成自动点赞、广告屏蔽、定时停止、多 APP 轮换、屏幕常亮等扩展任务。

## ✨ 核心功能

### 1. 全场景自动滚动
- 6 大预设场景，覆盖主流可滑动应用
- 智能识别可滚动节点（RecyclerView / ListView / ScrollView / WebView / ViewPager2）
- 找不到节点时自动回退全屏手势
- 拟人化参数（随机间隔 + 随机时长 + 随机位置偏移）

### 2. 6 大场景模板

| 场景 | 应用示例 | 推荐间隔 | 特性 |
| :--- | :--- | :---: | :--- |
| 短视频 | 抖音、快手、TikTok | 3-20s | 支持点赞 |
| 新闻资讯 | 今日头条、腾讯新闻 | 5-25s | - |
| 小说阅读 | 番茄小说、起点 | 8-30s | - |
| 社交动态 | 微博、小红书、知乎 | 4-18s | 支持点赞 |
| 直播挂机 | 抖音直播、虎牙、斗鱼 | 30-90s | 不滑动只挂机 |
| 自定义通用 | 所有可滑动应用 | 3-20s | - |

### 3. 扩展任务（8 项）

- **自动点赞**：滑动后按概率双击屏幕中央（仅短视频/社交场景）
- **自动关闭广告弹窗**：识别「跳过/关闭/知道了」等按钮自动点击
- **定时停止**：运行 N 分钟后自动停止（悬浮窗显示倒计时）
- **多 APP 轮换**：在当前场景的多个 APP 间定时切换
- **屏幕常亮**：WakeLock 防止自动锁屏
- **操作记录器**：录制你的点击 / 长按 / 滑动，生成可回放脚本（控制页入口）
- **看广告得金币（高风险）**：扫描「看广告得金币」等入口并自动观看激励视频，需「开关 + 风险确认」双条件才启用
- **统计看板**：实时展示本次运行的滚动 / 点赞 / 广告屏蔽 / 激励次数与运行时长

### 4. 悬浮窗控制

- 单击：开始 / 停止
- 长按拖动：松手自动吸附到左右边缘
- 倒计时显示：定时停止启用时实时显示
- 前台服务通知：含剩余时长

### 5. 清爽科技风 UI

- 底部导航三页：控制 / 场景 / 任务
- 卡片化布局 + 圆角边框 + 柔和蓝青配色
- 状态颜色提示 + 实时广播刷新

### 6. 操作记录器

把你在手机上的操作「录制」成可回放脚本，类似 Auto.js 的录制功能：

- 控制页 → 「操作记录器」进入脚本列表
- 点「开始录制」后本页退到后台，切到目标 APP 正常操作即可（点击 / 长按 / 列表滑动会被记录，最多 300 步）
- 屏幕上出现录制悬浮条，点「结束」保存脚本
- 在脚本列表点「运行」可回放；支持设置循环次数与倍速
- 脚本以 JSON 存于应用私有目录，可导出到外部存储

> ⚠️ 录制基于无障碍事件，部分自绘界面（游戏、Flutter / Canvas 页面）可能捕获不到操作。

### 7. 看广告得金币（高风险）

自动扫描页面上的「看广告得金币 / 领金币 / 免费领取」等入口并点击进入激励视频，观看期内暂停滚动、并周期性点掉「关闭 / 跳过」按钮，结束后恢复滚动。

- **双重保险**：必须在任务页先勾选「我已了解封号风险并愿意自担」，再开启开关，功能才会真正生效
- **可调参数**：尝试间隔（2-60 分钟）、激励入口关键词（可在任务页自由增删）
- **风控保护**：低电量 / 非 Wi-Fi / 非生效应用清单内时自动跳过，不打断广告观看

### 8. 统计看板

任务页顶部的实时面板，展示本次自动滚动的累计数据：

| 指标 | 含义 |
| :--- | :--- |
| 滚动次数 | 已执行的滑动手势数 |
| 点赞次数 | 自动点赞触发次数 |
| 关闭广告 | 被自动点掉的广告弹窗数 |
| 看广告激励 | 进入激励视频的次数 |
| 运行时长 | 本次服务自启动以来经过的时间 |

数据每秒刷新，停止滚动后清零。

## 📱 使用步骤

### 1. 编译

```bash
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

APK安装包网盘下载地址：[自动刷视频](https://www.guangyapan.com/s/1905445185801343001_aerIxeS_zVounKdp#/share "自动刷视频")

APK安装包网盘下载地址：[自动刷视频（快速刷）](https://www.guangyapan.com/s/1915616617208500243_aerIxeS_zVounKdp#/share "自动刷视频（快速刷）")

APK安装包：[自动刷视频](https://github.com/qqbn2027/autoscroll/releases "自动刷视频")

### 2. 配置

1. 打开应用 → 「场景」页选择要刷的内容类型
2. 「任务」页开启需要的扩展功能（点赞/广告屏蔽/定时停止/轮换/屏幕常亮；看广告得金币需额外勾选风险确认）
3. 「控制」页调整基础参数（滑动间隔 + 时长）；如需录制操作脚本，可从「控制」页进入「操作记录器」
4. 授予无障碍服务 + 悬浮窗权限
5. 点击「启动服务」→ 单击悬浮球开始；「任务」页顶部统计看板会实时累计数据

### 3. 控制

- 单击悬浮球：开始/停止
- 长按悬浮球：拖动位置
- 悬浮球上方会显示倒计时（定时停止启用时）

## ⚙️ 参数说明

### 基础参数
| 参数 | 范围 | 说明 |
| :--- | :---: | :--- |
| 最小/最大滑动间隔 | 1-60s | 两次滑动间随机等待 |
| 最小/最大滑动时长 | 100-3000ms | 单次手势随机持续时间 |
| 仅当前场景应用生效 | 开关 | 非场景应用自动跳过 |

### 任务参数
| 参数 | 范围 | 说明 |
| :--- | :---: | :--- |
| 自动点赞概率 | 0-100% | 每次滑动后按概率触发双击 |
| 定时停止时间 | 1-180min | 自动停止倒计时 |
| APP 轮换间隔 | 1-60min | 切换到下一 APP 的间隔 |
| 看广告得金币间隔 | 2-60min | 两次尝试进入激励视频的最小间隔 |
| 激励入口关键词 | 可增删 | 命中即尝试点击进入（默认 14 条） |

## ⚠️ 注意事项

1. **电量**：长时间运行较耗电，建议充电时使用
2. **流量**：自动滚动持续消耗流量，Wi-Fi 环境为宜
3. **风控**：抖音/快手等有反自动化机制，建议使用默认或更慢间隔
4. **厂商定制**：小米/华为/OPPO/vivo 可能需额外开启「后台弹出界面」「自启动」
5. **合规使用**：仅供学习与个人试用，请勿用于刷量/盈利/黑灰产
6. **⚠️ 看广告得金币封号风险**：该任务模拟点击进入激励视频，属于典型的广告激励作弊特征，**极易被平台风控识别导致账号限流、金币清零甚至封号**。务必在任务页勾选风险确认后再开启，并仅建议在小号 / 测试号上使用；由此产生的任何封号或损失由使用者自行承担
