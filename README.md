# 自动刷视频

一款基于 Android **无障碍服务**的零代码自动滚动工具，覆盖短视频、新闻资讯、小说阅读、社交动态、直播挂机等可滑动应用。以「拟人化」为核心：贝塞尔曲线轨迹、分段变速、长尾分布节奏、疲劳曲线、卡死自恢复，最大限度降低被平台风控识别的概率。内置自动点赞、广告屏蔽、详情流、定时运行、多 APP 轮换、操作记录器、统计看板等能力。

## ✨ 核心功能

### 1. 全场景自动滚动
- 7 大预设场景（含自动识别），覆盖主流可滑动应用
- 智能识别可滚动节点（RecyclerView / ListView / ScrollView / WebView / ViewPager2），找不到节点自动回退全屏手势
- **拟人化引擎**（`human/` 纯逻辑包）：三次贝塞尔弓形轨迹 + easeOutCubic 快起慢收 + ±2.5px 生理抖动；停留时长用对数正态分布（长尾）+ 疲劳曲线 + 偶发长驻留；辅以屏幕指纹卡死分级自恢复、列表 / 详情页分类、多 APP 轮换规划

### 2. 7 大场景模板

| 场景 | 应用示例 | 推荐间隔 | 特性 |
| :--- | :--- | :---: | :--- |
| 短视频 | 抖音、快手、TikTok | 3-20s | 支持点赞 |
| 新闻资讯 | 今日头条、腾讯新闻 | 5-25s | 启用详情流 |
| 小说阅读 | 番茄小说、起点 | 8-30s | 翻页模式 |
| 社交动态 | 微博、小红书、知乎 | 4-18s | 支持点赞 + 详情流 |
| 直播挂机 | 抖音直播、虎牙、斗鱼 | 30-90s | 不滑动只挂机 |
| 自定义通用 | 所有可滑动应用 | 3-20s | 自定义手势序列 |
| 自动识别 | 按当前 APP 自动匹配 | 随映射场景 | 免手动切换 |

> 滚动策略由场景模板自动选定：`VERTICAL`（竖向滑动）、`PAGE`（小幅翻页）、`IDLE`（直播挂机只保活）。选择「自动识别」后，内置 21 个常用 App 包名映射会按前台应用自动套用最合适的场景模板，未收录的 App 回退通用场景。

### 3. 拟人化细节（核心亮点）

- **轨迹**：贝塞尔曲线生成带弧度的弓形轨迹 + 逐点生理抖动，首尾精确对齐起终点
- **变速**：API 26+ 用 `continueStroke` 分段拼接，按各段路径长度分配时长，呈现「快起慢收」
- **节奏**：停留间隔用对数正态长尾分布（多数快、偶发长停）+ 疲劳曲线（跑得越久越慢）+ 偶发长驻留
- **自恢复**：对屏幕文本取 FNV 指纹，连续无变化时分级干预——关弹窗 → 按返回 → 重启应用
- **详情流**：新闻 / 社交场景自动「点开列表条目 → 详情页浏览（按概率读完或随机停留）→ 返回列表」，模拟真人刷-看-回

### 4. 扩展任务（设置面板内统一配置）

所有开关集中在一个「设置」底部弹窗（由控制页「基础参数」卡片进入），按「基础参数 / 任务功能」分组：

- **自动点赞**：滑动后按概率双击屏幕中央（短视频 / 社交场景）
- **自动关闭广告弹窗**：识别「跳过 / 关闭 / 知道了」等按钮自动点击（关键词可自定义）
- **详情流**：新闻 / 社交场景的列表-详情拟人浏览闭环（可调停留时长、读完概率、翻页上限）
- **定时停止**：运行 N 分钟后自动停止（悬浮窗显示倒计时）
- **多 APP 轮换**：在多个应用间定时切换（失败自动下线、全体复活）
- **屏幕常亮**：WakeLock + 悬浮窗保持屏幕常亮
- **定时运行**：每日多时段窗口（支持跨午夜、最多 8 段），到点自动启停
- **进程恢复**：无障碍服务被系统回收后自动恢复滚动（尊重定时窗口）
- **低电量暂停 / 仅 Wi-Fi**：电量低于阈值或非 Wi-Fi 时暂停滚动
- **应用黑白名单**：白名单只刷指定应用，黑名单跳过指定应用
- **看广告得金币（高风险）**：需「开关 + 风险确认」双条件，带冷静期风控
- **参数方案预设**：一键保存 / 切换整套运行参数

### 5. 操作记录器

把手机上的操作「录制」成可回放脚本：

- 「记录器」Tab 进入脚本列表；点「开始录制」本页退后台，切到目标 APP 正常操作即可（点击 / 长按 / 列表滑动，最多 300 步）
- 屏幕出现录制悬浮条，点「结束」保存脚本
- 点「运行」可回放，支持**循环次数与倍速**
- **条件分支**：任一步骤可设「条件」——仅当屏幕出现指定文本才执行，否则跳过（线性脚本具备 if 语义）
- **跨分辨率回放**：脚本记录录制时的屏幕分辨率，回放时坐标按比例缩放，换机 / 旋转屏幕不跑偏
- 脚本以 JSON 存于应用私有目录，支持导出 / 导入 / 重命名 / 删除，可在应用间分享

> ⚠️ 录制基于无障碍事件，部分自绘界面（游戏、Flutter / Canvas 页面）可能捕获不到操作。

### 6. 看广告得金币（高风险）

自动扫描「看广告得金币 / 领金币 / 免费领取」等入口并点击进入激励视频，观看期内暂停滚动并点掉「关闭 / 跳过」按钮，结束后恢复滚动。

- **双重保险**：必须在设置面板先勾选「我已了解封号风险并愿意自担」，再开启开关才生效
- **可调参数**：尝试间隔（2-60 分钟）、激励入口关键词（可自由增删）
- **冷静期风控**：连续 5 次未命中激励入口进入 30 分钟冷静期，不再高频触发高危点击
- 低电量 / 非 Wi-Fi 时自动跳过，不打断广告观看

### 7. 统计看板与趋势

「统计」页实时看板展示本次运行累计数据，数据每秒刷新，停止后清零：

| 指标 | 含义 |
| :--- | :--- |
| 滚动次数 | 已执行的滑动手势数 |
| 点赞次数 | 自动点赞触发次数 |
| 关闭广告 | 被自动点掉的广告弹窗数 |
| 看广告激励 | 进入激励视频的次数 |
| 运行时长 | 本次服务自启动以来经过的时间 |

下方「近 7 天」卡片展示最近每日滚动次数趋势（数据按天落盘，保留最近 30 天）。支持导出统计 CSV。

### 8. 主界面与工具页

- **顶部应用栏 + 底部导航三页**：控制 / 统计 / 记录器
- **控制页**：使用说明、运行状态、基础参数（设置面板入口）、无障碍 / 悬浮窗权限、启动服务、运行日志、健康诊断、应用中心
- **健康诊断页**：一键检查无障碍 / 悬浮窗 / 通知权限与运行状态，附跳转修复入口与健康结论
- **应用中心**：统一管理「轮换应用池」与「过滤名单」，一处设置全局过滤模式（关闭 / 白名单 / 黑名单）
- **深色模式**：跟随系统深浅色自动切换
- **清爽卡片化 UI**：圆角边框 + 蓝青配色 + 实时状态刷新

### 9. 悬浮窗控制

- 单击：开始 / 停止；长按拖动：松手自动吸附边缘
- 定时停止启用时悬浮窗显示倒计时
- 前台服务通知自带「停止」按钮，一键停止滚动并关闭悬浮窗

### 10. 其他内置能力

- **Toast 即时响应**：检测「加载失败 / 网络错误」立即重置卡死检测并快速重试；激励观看期检测「已到账」自动提前结束（带最短观看保护）
- **多 APP 轮换应用池**：在设置面板 / 应用中心选择要轮换的包名池，池为空则不轮换
- **自定义手势序列**：自定义场景下可编排「点击 / 双击 / 上滑 / 下滑 / 左滑 / 右滑 / 点击文本 / 等待」多步组合循环执行
- **桌面小部件**：一键开始 / 停止并展示运行状态与今日滚动数

## 📱 使用步骤

### 1. 编译

```bash
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

APK 安装包网盘下载地址：[自动刷视频](https://www.guangyapan.com/s/1932294827152785416_aerIxeS_zVounKdp "自动刷视频")

### 2. 配置

1. 打开应用 → 「控制」页点「基础参数」打开设置面板 →「场景选择」选内容类型（选「自动识别」可免手动切换）
2. 设置面板里按需开启扩展任务（点赞 / 广告 / 定时 / 轮换 / 常亮 / 定时运行 / 保护等），可用「参数方案」一键保存 / 切换整套配置
3. 授予无障碍服务 + 悬浮窗权限（可在「健康诊断」页一键检查 / 跳转）
4. 点「启动服务」→ 单击悬浮球开始；「统计」页实时查看数据

### 3. 控制

- 单击悬浮球：开始 / 停止；长按拖动：调整位置
- 悬浮球上方显示倒计时（定时停止启用时）

## ⚙️ 参数说明

### 基础参数（设置面板）
| 参数 | 范围 | 说明 |
| :--- | :---: | :--- |
| 最小 / 最大滑动间隔 | 1-60s | 两次滑动间随机等待 |
| 最小 / 最大滑动时长 | 100-3000ms | 单次手势随机持续时间 |
| 广告关闭关键词 | 可增删 | 命中即尝试点击关闭 |
| 参数方案预设 | 可增删 | 一键保存 / 切换整套参数 |

### 任务参数（设置面板）
| 参数 | 范围 | 说明 |
| :--- | :---: | :--- |
| 自动点赞概率 | 0-100% | 每次滑动后按概率触发双击 |
| 详情流停留 | 6-30s | 详情页最短 / 最长停留 |
| 完整读完概率 | 0-100% | 进入详情页后完整读完的比例 |
| 单篇最多翻页 | 1-20 | 详情页最多滚动次数 |
| 定时停止时间 | 1-180min | 自动停止倒计时 |
| APP 轮换间隔 | 1-60min | 切换到下一 APP 的间隔 |
| 定时运行时段 | 多段 × 起止 | 每日生效窗口（支持跨午夜，最多 8 段） |
| 电量阈值 | 5-100% | 低于且未充电时暂停 |
| 看广告得金币间隔 | 2-60min | 两次尝试进入激励视频的最小间隔 |
| 激励入口关键词 | 可增删 | 命中即尝试点击进入 |

## ⚠️ 注意事项

1. **电量**：长时间运行较耗电，建议充电时使用
2. **流量**：自动滚动持续消耗流量，Wi-Fi 环境为宜
3. **风控**：抖音 / 快手等有反自动化机制，建议使用默认或更慢间隔
4. **厂商定制**：小米 / 华为 / OPPO / vivo 可能需额外开启「后台弹出界面」「自启动」
5. **合规使用**：仅供学习与个人试用，请勿用于刷量 / 盈利 / 黑灰产
6. **⚠️ 看广告得金币封号风险**：该任务模拟点击进入激励视频，属于典型的广告激励作弊特征，**极易被平台风控识别导致账号限流、金币清零甚至封号**。务必在设置面板勾选风险确认后再开启，并仅建议在小号 / 测试号上使用；由此产生的任何封号或损失由使用者自行承担
